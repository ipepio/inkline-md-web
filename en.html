Features

Enough to write, nothing in the way

Three modes, one workspace, and a way out to paper or HTML when the document is ready.

  • Three modes, one document

    Reading, editing and a split view with live preview. The divider split is remembered per document.

  • File workspace

    Folder tree, recents and tabs. A context menu opens a file in a split, reveals it in Finder or copies its path.

  • Command palette

    One field for everything with ⌘K: jump to a file, reopen a recent one or run a command.

  • CodeMirror 6 editor

    Line numbers, Markdown highlighting, a formatting toolbar, optional word wrap and your text size.

  • GitHub Flavored viewer

    Tables, task lists and code blocks highlighted with Shiki. Reading gets a real line length.

  • Mermaid diagrams

    mermaid blocks render inside the document: no second tool, no leaving the file.

  • Export

    Standalone HTML, a Markdown copy and Office formats (.docx, .odt). Printing goes through the system browser.

  • Settings that persist

    Light, dark or system theme, an optional serif reading font and global zoom with ⌘+ / ⌘−.

  • Local-first, for real

    Files are written with write-then-rename and never leave your machine: no account, no server in between.

Under the hood

A native binary, not another browser tab

The interface is web; the window, the disk and the system dialogs are native.

Repository: ipepio/inkline-md · Apache-2.0 license.
ShellTauri 2 (Rust)
UIReact 18 + TypeScript
BuildVite 6
StylingTailwind CSS 4 + shadcn/ui
EditorCodeMirror 6
Markdownmarkdown-it (GFM) + Shiki + Mermaid

Atomic writes

A temp file is written and renamed: a power cut never leaves a half-saved document.

No network by default

No sync, no telemetry. What you open is yours and stays where it is.

One window

Viewer, editor and exporter share the same document, position and theme.

Before you download

Short questions

What is the demo above?
The real frontend of the app, compiled for the browser. Write, switch modes and export HTML; opening and saving local files needs the desktop version.
Where do my documents live?
Wherever you decide. Inkline only reads and writes the files you open, with atomic writes and no cloud copy.
Why does the OS warn me when I open the installer?
The binaries come from an independent project and are neither signed nor notarized. Use the “open anyway” flow on macOS or “more info → run anyway” on Windows.
Is there a mobile or web version?
No. Inkline is a desktop app: it needs file-system access. The browser demo shows the frontend; it is not a separate product.
How do I build it?
With Node 22+, pnpm and stable Rust: pnpm install, then pnpm tauri dev. The desktop build is packaged with pnpm tauri build.
Can I use the code?
Yes: Apache-2.0, public on GitHub from day one. The project is inklineMD; the app is Inkline.

inklineMD is the project; Inkline is the desktop app. Built with Tauri, React and Vite. Apache-2.0 license.
